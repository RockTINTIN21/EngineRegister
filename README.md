# EngineRegister — система учёта и идентификации электродвигателей

**MotorID** — это внутренняя система для предприятия, позволяющая вести учёт электродвигателей, хранить их технические паспорта и идентифицировать оборудование с помощью NFC-меток.  
Проект создан для автоматизации процессов на заводе и был моим первым коммерческим приложением, где я применял и активно изучал **React** и современные инструменты фронтенда.

---

## Функциональность

- **Регистрация электродвигателей**
  - Добавление нового оборудования
  - Редактирование и просмотр паспортов
  - Хранение технических характеристик в базе данных

- **Идентификация через NFC**
  - Генерация NFC-меток
  - Сканирование ведёт на страницу конкретного двигателя
  - Упрощение сервиса для технических специалистов на производстве

- **Удобный интерфейс**
  - Интуитивные формы ввода
  - Список всех двигателей
  - Детальная карточка оборудования
